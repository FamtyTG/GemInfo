Диаграмма в формате DrawIO: [diagrams/screens_flow.drawio](diagrams/screens_flow.drawio).

Мокапы экранов (SVG) лежат в папке [mockups/](mockups/) и генерируются из реальных
текстов и кнопок бота командой `make mockups`
(`python scripts/generate_mockups.py`).

Команда `/start` возвращает пользователя в главное меню независимо от того,
на каком экране он находится. При самом первом обращении к боту показывается
Экран 1 «Приветствие».

Состояние диалога (текущий экран, выбранные жанры, страница, открытая игра)
хранится в `StateStorage` (`gamehunter/presentation/state.py`) в памяти процесса.
Если бот перезапустили и пользователь нажал кнопку старого сообщения, он увидит
сообщение `STATE_LOST` и вернётся в главное меню.

## Экран 1. Приветствие

**Видеоинструкция:** вместе с приветствием бот отправляет ролик
`gamehunter/assets/tutorial/01_start.mp4` с подписью-шагами
(`texts.tutorial_caption`).

Мокап: [mockups/01_start.svg](mockups/01_start.svg)

**Когда показывается:** пользователь впервые пишет боту (любое сообщение или `/start`),
если состояния для него ещё нет.

**Текст:** `texts.START_WELCOME`

> Добро пожаловать в GameHunter
> Чат-бот, который помогает подобрать видеоигру по интересам, жанрам,
> возрасту и франшизе (IP).
> /start — переведёт Вас в главное меню, где бы Вы ни находились.

**Клавиатура:** обычная (reply), одна кнопка «Старт».

| Кнопка | Переход |
|--------|---------|
| Старт | Экран 2 «Главное меню» |

**Что сохраняется:** создаётся контекст пользователя (`UserContext`) — с этого
момента бот помнит, на каком экране находится пользователь.

## Экран 2. Главное меню

Мокап: [mockups/02_main_menu.svg](mockups/02_main_menu.svg)

**Когда показывается:** после «Старт», по команде `/start` в любой момент,
по кнопке «В главное меню» и когда состояние шага потеряно.

**Текст:** `texts.MAIN_MENU_WELCOME`

> Добро пожаловать в GameHunter
> Выберите кнопку из главного меню.

**Клавиатура:** обычная (reply), четыре ряда:

| Ряд | Кнопки | Переход |
|-----|--------|---------|
| 1 | Подобрать игру · Игры по франшизе | Экран 3 · Экран 6 |
| 2 | Моя анкета | Экран 9 |
| 3 | Во что я играл · Избранное | Экран 10 · Экран 12 |

**Особые случаи:**

| Ситуация | Поведение |
|----------|-----------|
| Пользователь пишет произвольный текст | «Нераспознанная команда. Пожалуйста, нажмите выбранную кнопку в меню.» |
| Пользователь присылает фото, видео, голосовое, стикер, локацию | Сообщение игнорируется (бот не отвечает) |

## Экран 3. Выбор интересов (жанры)

**Видеоинструкция:** вместе с экраном бот отправляет ролик
`gamehunter/assets/tutorial/03_picking_genres.mp4` с подписью-шагами.

Мокап: [mockups/03_picking_genres.svg](mockups/03_picking_genres.svg)

**Когда показывается:** кнопка «Подобрать игру», а также «Другие жанры» из
Экрана 4 и «Назад» из Экрана 4.

**Что делает бот:** запрашивает справочник жанров у RAWG (`GET /genres`),
берёт первые `MAX_GENRES` (по умолчанию 12) и сохраняет их в контексте.

**Текст:** `texts.format_genres_selection(...)` — заголовок `GENRES_TITLE`,
список жанров (отмеченные с «✔»), строка «Выбрано: …» и подсказка `GENRES_FOOTER`.

**Inline-кнопки:** жанры по два в ряд, затем три ряда действий:

| Кнопка | Поведение |
|--------|-----------|
| «Название жанра» / «✔ Название жанра» | отмечает или снимает жанр, экран обновляется (callback `g:{slug}`) |
| Показать подборку | переход на Экран 4 с выбранными жанрами (callback `pick_show`) |
| Показать всё | переход на Экран 4 без фильтра по жанрам, интересы анкеты игнорируются (callback `pick_all`) |
| В главное меню | Экран 2 |

**Особые случаи:**

| Ситуация | Поведение |
|----------|-----------|
| Жанры не выбраны, а в анкете интересов нет | «Вы не выбрали ни одного жанра. Нажмите «Показать всё» или отметьте жанры ещё раз.» — пользователь остаётся на Экране 3 |
| Жанры не выбраны, но в анкете есть интересы | подборка строится по интересам из анкеты |
| RAWG недоступен | `GenresUnavailableError.user_message` — «Не удалось получить список жанров…» + кнопки «Другие жанры» и «В главное меню» |
| Список жанров не сохранился (бот перезапускали) | бот заново запрашивает жанры и показывает экран |

## Экран 4. Подборка игр

**Видеоинструкция:** вместе со списком бот отправляет ролик
`gamehunter/assets/tutorial/04_game_list.mp4` с подписью-шагами
(при листании страниц ролик повторно не шлётся).

Мокап: [mockups/04_game_list.svg](mockups/04_game_list.svg)

**Что делает бот:**

1. читает анкету пользователя (`ProfileService.get_profile`);
2. получает идентификаторы уже сыгранных игр (`LibraryService.played_game_ids`);
3. собирает запрос `GameQuery` (жанры из контекста) и дополняет его данными
   анкеты (`GameService.merge_with_profile`): платформы, возраст, исключение
   сыгранных игр, сортировка `-rating`;
4. запрашивает каталог (`GET /games`) и для части игр догружает карточки, чтобы
   узнать возрастной рейтинг (`DETAILS_FETCH_LIMIT`, по умолчанию 8);
5. отбрасывает игры не по возрасту и показывает страницу из `MAX_GAMES` игр.

**Текст:** `texts.format_games(...)`

> Подборка игр для Вас:
>
> Фильтры: жанры: Action, RPG; платформы: PC; возраст: 27
> Игры, в которые Вы уже играли, исключены из подборки.
> Страница 1 из 3
>
> 1. The Witcher 3: Wild Hunt
>    2015 · рейтинг 4.6 · RPG
> …
> Выберите игру, чтобы посмотреть карточку.

**Inline-кнопки:**

| Кнопка | Поведение |
|--------|-----------|
| «Выбрать игру N» | Экран 5 «Карточка игры» (callback `game:{id}`) |
| Назад / Вперёд | страницы подборки (callback `games:{page}`) |
| Другие жанры | Экран 3 |
| В главное меню | Экран 2 |

**Особые случаи:**

| Ситуация | Поведение |
|----------|-----------|
| Игр не найдено | `NoGamesFoundError.user_message` + кнопки «Другие жанры» и «В главное меню» |
| Все найденные игры не подходят по возрасту | то же сообщение — бот предлагает изменить интересы или снять фильтры анкеты |
| RAWG недоступен | «Не удалось получить список игр. Попробуйте ещё раз позже.» |
| Анкету прочитать не удалось | «Ошибка при работе с базой данных…» |
| Одна страница | кнопки «Назад»/«Вперёд» не показываются |

## Экран 5. Карточка игры

Мокап: [mockups/05_game_card.svg](mockups/05_game_card.svg)

**Когда показывается:** «Выбрать игру N» на Экранах 4, 8 и 12.

**Что делает бот:** запрашивает детали игры (`GET /games/{id}`), определяет
минимальный возраст по ESRB/PEGI (`AgePolicy`), проверяет по базе, играл ли
пользователь в эту игру и есть ли она в избранном.

**Сообщение:** обложка игры (если есть `image_url`) с подписью-карточкой;
если фото отправить не удалось — текст отдельным сообщением.

**Текст:** `texts.format_game_card(...)`

> Карточка игры:
>
> Название: The Witcher 3: Wild Hunt
> Выход: 19.05.2015
> Рейтинг: 4.6 · Metacritic 93
> Жанры: RPG, Action, Adventure
> Платформы: PC, PlayStation 4, Xbox One, Nintendo Switch
> Возрастной рейтинг: M (17+)
> Разработчик: CD PROJEKT RED
> Издатель: CD PROJEKT RED
> Среднее время прохождения: 50 ч.
> Магазины: Steam, GOG, PlayStation Store
> Метки: Открытый мир, Сюжет, Славянское фэнтези
> Ваш регион: Kazan, Tatarstan Republic, Russia, валюта RUB
>
> ✔ Вы уже играли в эту игру.
> ★ Игра в избранном.
>
> Третья часть серии игр по книгам Анджея Сапковского…

**Inline-кнопки:**

| Кнопка | Поведение |
|--------|-----------|
| Уже играл | добавляет игру в `played_games`, карточка обновляется (callback `played:{id}`) |
| В избранное / Убрать из избранного | переключает избранное (callback `fav:{id}`) |
| Назад | возвращает к списку, из которого открыта карточка: Экран 4, 8 или 12 (callback `back_games`) |
| В главное меню | Экран 2 |

**Особые случаи:**

| Ситуация | Поведение |
|----------|-----------|
| Игра уже отмечена как сыгранная | «Эта игра уже есть в Вашем списке «Во что я играл».» |
| Игры нет в каталоге | `GameNotFoundError.user_message` — «Игра не найдена. Вернитесь к списку и выберите игру заново.» |
| Обложки нет | карточка отправляется только текстом |
| Telegram не принял фото | автоматически отправляется текст (поведение шлюза) |
| Карточка открыта из избранного, а игры в избранном уже нет | кнопка снова называется «В избранное» |
| Список, из которого открыта карточка, не сохранился | «Данные предыдущего шага не сохранились…» и возврат в главное меню |

## Экран 6. Поиск по франшизе — ввод названия

Мокап: [mockups/06_franchise_input.svg](mockups/06_franchise_input.svg)

**Когда показывается:** кнопка «Игры по франшизе», «Другая франшиза» с Экрана 8,
а также когда франшиза не найдена.

**Текст:** `texts.FRANCHISE_INPUT_PROMPT`

> Введите название франшизы (IP), по которой нужно найти игры.
> Например: Marvel, Star Wars, Warcraft, Assassin's Creed.

**Клавиатура:** обычная клавиатура скрывается (`ReplyKeyboardRemove`) —
пользователь вводит текст. Бот ждёт текстовое сообщение.

**Особые случаи:**

| Ситуация | Поведение |
|----------|-----------|
| Пустое сообщение | «Введите название франшизы, например: Marvel.» + повторный ввод |
| Франшиза не найдена | «Франшиза не найдена. Проверьте название (например: Marvel, Star Wars, Warcraft) и попробуйте ещё раз.» + повторный ввод и кнопка «Другая франшиза» |
| RAWG недоступен | «Не удалось выполнить поиск по франшизе. Попробуйте ещё раз позже.» |

> 2. Marvel Ultimate Alliance
>    игр в каталоге: 4
>

**Inline-кнопки:** «Выбрать франшизу N» (callback `frs:{index}`) и «Отмена»
(возврат в главное меню).

## Экран 9. Моя анкета

Мокап: [mockups/09_profile.svg](mockups/09_profile.svg)

**Что делает бот:** читает анкету из `user_profiles` (создаёт пустую при первом
обращении) и считает число сыгранных игр.

**Текст:** `texts.format_profile(...)`

> Моя анкета:
>
> Возраст: 27 лет
> Интересы (жанры): Action, RPG
> Платформы: PC, PlayStation
> Регион: Kazan, Tatarstan Republic, Russia
>    страна: RU
>    часовой пояс: Europe/Moscow
>    валюта: RUB
>    определён по IP: 5.188.0.1
>
> Анкета используется при подборе игр: …

**Inline-кнопки:**

| Кнопка | Переход / действие |
|--------|--------------------|
| Указать возраст | Экран 9а (callback `p_age`) |
| Убрать возраст | очищает возраст, показывает анкету (callback `p_age_reset`) |
| Выбрать интересы | Экран 9б (callback `p_genres`) |
| Выбрать платформы | Экран 9в (callback `p_platforms`) |
| Определить регион по IP | Экран 9г (callback `p_ip`) |
| Убрать регион | очищает регион, показывает анкету (callback `p_ip_reset`) |
| В главное меню | Экран 2 |

Кнопки «Убрать возраст» и «Убрать регион» появляются только тогда, когда
соответствующее значение заполнено.

**Особые случаи:**

| Ситуация | Поведение |
|----------|-----------|
| Возраст не указан | «Возраст: не указан» |
| Интересы или платформы не выбраны | «не выбраны» в соответствующей строке |
| Регион не определён | «Регион: не определён» |
| База данных недоступна | «Ошибка при работе с базой данных. Попробуйте ещё раз позже.» |

## Экран 9г. Регион по IP-адресу

Мокап: [mockups/09d_profile_region.svg](mockups/09d_profile_region.svg)

**Текст:** `texts.PROFILE_IP_PROMPT`

> Пришлите Ваш публичный IP-адрес — по нему бот определит страну, город,
> часовой пояс и валюту.
> Узнать свой IP-адрес можно на сайте 2ip.ru. Пример: 8.8.8.8

Клавиатура скрыта, бот ждёт текст. Адрес выделяется из сообщения регулярным
выражением, поэтому можно написать «мой адрес 5.188.0.1, смотрел на 2ip.ru».

**Что делает бот:** проверяет адрес (`ProfileService.validate_ip`), отправляет
его в сервис геолокации (`GET https://ipapi.co/{ip}/json/`) и сохраняет
`Region` в анкету.

| Ситуация | Поведение |
|----------|-----------|
| Корректный публичный адрес | «Регион определён и сохранён в анкете.» + Экран 9 |
| Адрес не найден в сообщении или некорректен | «Некорректный IP-адрес. Пример правильного адреса: 8.8.8.8…» + повторный ввод |
| Локальный адрес (10.x, 172.16–31.x, 192.168.x, 127.x, ::1) | «Это локальный (внутренний) IP-адрес — по нему нельзя определить регион…» + повторный ввод |
| Сервис геолокации недоступен или исчерпан лимит | «Не удалось определить регион по IP-адресу…» + Экран 9 |
| Сервис вернул данные без города и страны | регион не сохраняется, показывается сообщение об ошибке |

## Экран 13. Подбор игр по возрастному рейтингу

**Когда показывается:** по кнопке «Игры по возрастному рейтингу» из главного
меню и по кнопке «🎂 Изменить возрастной рейтинг» в подборке игр (Экран 4),
если рейтинг уже выбран.

**Суть:** пользователь выбирает категорию (3+, 6+, 10+, 13+, 17+, 18+) —
она сохраняется в состоянии (`UserContext.age_rating`) и на время подборки
подменяет возраст из анкеты: `GameService` отфильтрует игры по рейтингам
ESRB/PEGI из каталога RAWG (игры без рейтинга проходят всегда).

**Текст:** `texts.AGE_RATING_TITLE`; если рейтинг уже выбран, добавляется
`texts.AGE_RATING_CURRENT` с подписью категории.

**Клавиатура:** inline — шесть категорий по две в ряд
(`keyboards.age_rating_keyboard`, callback `age_pick:{age}`), выбранная
отмечена «✔»; ниже «Сбросить рейтинг» (`age_reset`) и «В главное меню».

**Поведение после выбора:** показывается Экран 4 с заголовком
`texts.GAMES_TITLE_WITH_RATING` («🎂 Возрастной рейтинг: 17+ — взрослым (ESRB M)»)
и дополнительной строкой «🎂 Изменить возрастной рейтинг» в клавиатуре.

**Особые случаи:**

| Ситуация | Поведение |
|----------|-----------|
| Рейтинг сброшен | «Возрастной рейтинг сброшен…» (`texts.AGE_RATING_RESET_DONE`) + Экран 13; подборка снова по возрасту из анкеты |
| `age_pick` с неизвестным возрастом | возврат к Экрану 13 без изменений |
| `age_pick` без значения | «Нераспознанная команда…» |

## Сводка callback-данных

Все inline-кнопки кодируются строкой `{действие}` или `{действие}:{значение}`
(класс `CallbackAction` и функции-строители в `gamehunter/presentation/keyboards.py`).

| Callback | Экран | Значение |
|----------|-------|----------|
| `menu` | 2 | — |
| `pick` | 3 | — |
| `g:{slug}` | 3 | slug жанра |
| `pick_show` | 3 → 4 | — |
| `pick_all` | 3 → 4 | — |
| `games:{page}` | 4 | номер страницы |
| `game:{id}` | 4, 8, 12 → 5 | идентификатор игры |
| `played:{id}` | 5 | идентификатор игры |
| `fav:{id}` | 5 | идентификатор игры |
| `back_games` | 5 → 4, 8, 12 | — |
| `fr` | 6 | — |
| `frs:{index}` | 7 → 8 | порядковый номер франшизы |
| `profile` | 9 | — |
| `p_age` / `p_age_reset` | 9, 9а | — |
| `p_genres` / `pg:{slug}` / `p_genres_done` | 9б | slug жанра |
| `p_platforms` / `pl:{id}` / `p_platforms_done` | 9в | идентификатор платформы |
| `p_ip` / `p_ip_reset` | 9, 9г | — |
| `lib:{page}` / `rec:{id}` / `rev:{id}` / `del:{id}` | 10, 11, 11а | страница / идентификатор записи |
| `favs:{page}` | 12 | номер страницы |
| `age` | 13 | — |
| `age_pick:{age}` | 13 → 4 | минимальный возраст категории |
| `age_reset` | 13 | — |

Неизвестные или неполные callback-данные (например `game:` без идентификатора)
не приводят к ошибке: пользователь получает «Нераспознанная команда…» и
остаётся на текущем экране.
