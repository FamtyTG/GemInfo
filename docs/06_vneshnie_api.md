# 06. Интеграция с внешними API

Все запросы выполняются библиотекой `requests` через общий клиент
`travelhunter/infrastructure/api/http_client.py` (`JsonHttpClient`), который
задаёт таймаут и единообразно обрабатывает сетевые ошибки.

| Сервис | Класс-клиент | Порт доменного слоя | Используется на экране |
|--------|--------------|---------------------|------------------------|
| Ninjas Holidays API | `NinjasHolidaysClient` | `HolidaysProvider` | Экран 3 |
| GeoNames | `GeoNamesClient` | `CityProvider` | Экраны 4, 5 |
| Wikipedia (MediaWiki Action API) | `WikipediaClient` | `CityInfoProvider` | Экран 6 |

---

## 1. Ninjas Holidays API — праздники

* Документация: <https://api-ninjas.com/api/holidays>
* Endpoint: `GET https://api.api-ninjas.com/v2/holidays`
* Авторизация: заголовок `X-Api-Key` (значение — из переменной `NINJAS_API_KEY`)

### Параметры запроса

| Параметр | Значение | Описание |
|----------|----------|----------|
| `country` | `RU` | код страны |
| `date` | `2026-01-01` | дата, задающая год (API отдаёт праздники за год указанной даты) |

### Пример запроса (как его выполняет бот)

```http
GET /v2/holidays?country=RU&date=2026-01-01 HTTP/1.1
Host: api.api-ninjas.com
X-Api-Key: <ключ из переменной окружения>
```

### Пример ответа

```json
[
  {
    "country": "Russia",
    "iso": "RU",
    "year": 2026,
    "date": "2026-08-22",
    "day": "Sa",
    "name": "Day of the State Flag",
    "type": "Observance"
  }
]
```

### Обработка ответа

1. Если вместо массива пришёл объект с полем `error` — ошибка «Не удалось получить
   список праздников. Попробуйте ещё раз позже.»;
2. Дата разбирается в нескольких форматах (`YYYY-MM-DD`, `DD/MM/YYYY`, `DD.MM.YYYY`,
   `YYYY/MM/DD`, `DD-MM-YYYY`) — функция `parse_holiday_date`;
3. Элементы без названия или без даты пропускаются;
4. `HolidayService` оставляет праздники в диапазоне [сегодня; сегодня + 7 дней],
   сортирует по дате и берёт не более 5.

## 2. GeoNames — поиск города

* Документация: <https://www.geonames.org/export/web-services.html>
* Endpoint: `GET https://secure.geonames.org/searchJSON`
* Авторизация: параметр `username` (значение — из переменной `GEONAMES_USERNAME`)

### Параметры запроса

| Параметр | Значение | Описание |
|----------|----------|----------|
| `q` | введённое пользователем название | нечёткий поиск по всем названиям |
| `maxRows` | `10` | несколько вариантов, чтобы выбрать наиболее подходящий |
| `featureClass` | `P` | только населённые пункты |
| `style` | `FULL` | полный набор полей (в том числе `population`) |
| `lang` | `ru` | язык ответа |
| `countryBias` | из настроек (по умолчанию пусто) | «мягкое» предпочтение стране |
| `username` | логин GeoNames | обязательный параметр |

### Пример ответа

```json
{
  "totalResultsCount": 1,
  "geonames": [
    {
      "geonameId": 524901,
      "name": "Москва",
      "lat": "55.7558",
      "lng": "37.6173",
      "countryName": "Russia",
      "adminName1": "Москва",
      "population": 12615882,
      "featureClass": "P",
      "featureCode": "PPLC"
    }
  ]
}
```

### Обработка ответа

1. Если `geonames` пуст — «Город не найден. Проверьте название города и попробуйте ещё раз.»;
2. Если вариантов несколько — выбирается населённый пункт с наибольшим `population`
   (так «Тула» находится в России, а не одноимённая деревня в другой стране);
3. Сохраняются `name`, `lat`, `lng` — они нужны на следующем экране;
4. Ошибки аккаунта GeoNames приходят в теле ответа в поле `status`
   (`user account disabled`, `daily limit exceeded`) — клиент преобразует их
   в `CitySearchUnavailableError`.

## 3. GeoNames — ближайшие города

* Endpoint: `GET https://secure.geonames.org/findNearbyPlaceNameJSON`

### Параметры запроса

| Параметр | Значение | Описание |
|----------|----------|----------|
| `lat`, `lng` | координаты города пользователя | получены на Экране 4 |
| `radius` | `500` | радиус поиска, км |
| `maxRows` | `limit` (сервис запрашивает 20) | количество результатов |
| `style` | `FULL` | полный набор полей |
| `lang` | `ru` | язык ответа |
| `username` | логин GeoNames | обязательный параметр |

### Пример ответа

```json
{
  "geonames": [
    {
      "geonameId": 480508,
      "name": "Тула",
      "lat": "54.2021",
      "lng": "37.6443",
      "distance": "172.45",
      "countryName": "Russia",
      "adminName1": "Тульская область",
      "population": 482873
    }
  ]
}
```

### Обработка ответа

`CityService.find_nearby_cities()`:

1. сортирует результаты по возрастанию `distance`;
2. исключает город, который ввёл пользователь (сравнение без учёта регистра);
3. удаляет дубликаты названий (районы одного города);
4. берёт первые 5 городов;
5. если городов не осталось — показывает сообщение об ошибке и возвращает в меню.

## 4. Wikipedia (MediaWiki Action API) — информация о городе

* Endpoint: `GET https://ru.wikipedia.org/w/api.php` (язык задаётся настройкой
  `WIKIPEDIA_LANGUAGE`)
* Авторизация не требуется

### Параметры запроса

| Параметр | Значение | Описание |
|----------|----------|----------|
| `action` | `query` | тип запроса |
| `format` | `json` | формат ответа |
| `prop` | `extracts\|pageimages` | краткое описание и изображение |
| `titles` | название выбранного города | страница для поиска |
| `redirects` | `1` | учитывать перенаправления |
| `exintro` | `1` | только вступление статьи |
| `explaintext` | `1` | текст без wiki-разметки |
| `pithumbsize` | `800` | ширина миниатюры изображения |
| `origin` | `*` | анонимный запрос |

### Пример ответа

```json
{
  "query": {
    "pages": {
      "12345": {
        "pageid": 12345,
        "title": "Тула",
        "extract": "Тула — город в России, административный центр Тульской области…",
        "thumbnail": {
          "source": "https://upload.wikimedia.org/wikipedia/commons/…/tula.jpg",
          "width": 800
        }
      }
    }
  }
}
```

### Обработка ответа

1. `pageid = -1` или поле `missing` — статья не найдена → `CityInfoUnavailableError`;
2. пустой `extract` — описание недоступно → `CityInfoUnavailableError`;
3. изображение берётся из `thumbnail.source`, при отсутствии — из `originalimage`;
4. если изображения нет, бот показывает информацию о городе текстом;
5. описание обрезается до 1000 символов по границе слова (`CityService._truncate`);
6. если Telegram не смог отправить изображение (например, ссылка недоступна),
   шлюз возвращает `False` и экран отправляет то же сообщение текстом.

## Обработка ошибок внешних сервисов

| Ситуация | Исключение | Сообщение пользователю |
|----------|-----------|------------------------|
| Таймаут запроса | `ExternalServiceError` | зависит от экрана (см. ниже) |
| Нет соединения | `ExternalServiceError` | то же |
| HTTP 4xx / 5xx | `ExternalServiceError` | то же |
| Ответ не является JSON | `ExternalServiceError` | то же |
| Не задан API-ключ / логин | `HolidaysUnavailableError`, `CitySearchUnavailableError` | сообщение об ошибке + предупреждение в логе при старте |
| Ошибка аккаунта GeoNames | `CitySearchUnavailableError` | «Не удалось найти город. Попробуйте ещё раз позже.» |
| Статья не найдена в Википедии | `CityInfoUnavailableError` | «Не удалось получить информацию о городе. Попробуйте ещё раз позже.» |

Сообщения по экранам:

* Экран 3 — «Не удалось получить список праздников. Попробуйте ещё раз позже.»;
* Экраны 4–5 — «Не удалось найти город. Попробуйте ещё раз позже.»;
* Экран 6 — «Не удалось получить информацию о городе. Попробуйте ещё раз позже.»

Во всех случаях бот продолжает работать: исключение перехватывается экраном
или декоратором `safe_handler`.

## Как получить ключи

| Сервис | Шаги |
|--------|------|
| Ninjas API | зарегистрироваться на <https://api-ninjas.com/> → личный кабинет → скопировать API-ключ → `NINJAS_API_KEY` |
| GeoNames | зарегистрироваться на <https://www.geonames.org/login> → открыть <https://www.geonames.org/manageaccount> → включить «Free Web Services» → `GEONAMES_USERNAME` |
| Wikipedia | ключ не требуется |
