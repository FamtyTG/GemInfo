# 10. Анимированные карточки интерфейса (Adobe After Effects)

Три анимированные карточки — **приветствие**, **выбор жанра**, **выбор игры** —
рисуются из настоящего интерфейса бота (тексты и кнопки берутся из
`gamehunter.presentation.texts` / `keyboards`, как и SVG-мокапы). Проект отдаёт
в After Effects сразу три вещи: готовые слои, точную раскадровку и черновые
GIF, по которым видно задуманное движение.

| Файл | Что это |
|------|---------|
| `docs/ae/cards/01_start.gif` | черновая анимация карточки «Приветствие» (0.9 МБ) |
| `docs/ae/cards/03_picking_genres.gif` | карточка «Выбор жанра» с отметками ✔ (0.9 МБ) |
| `docs/ae/cards/04_game_list.gif` | карточка «Выбор игры» (0.7 МБ) |
| `docs/ae/layers/<экран>/*.png` | слои карточки с прозрачностью: подложка, шапка, «печатает…», пузырь сообщения, ряды кнопок, клавиатура, подпись |
| `docs/ae/timeline.json` | тайминг-шит: размеры, позиции слоёв, шаги анимации в секундах и в кадрах AE (30 fps), easing |
| `docs/ae/preview.html` | живое превью «карточка сверху + текст снизу» |
| `docs/ae/import_layers.jsx` | скрипт AE: импорт слоёв, сборка композиции, ключевые кадры Opacity/Position |

Канва карточки — **1080×1350** (4:5), черновой GIF — 720 px шириной и 15 fps
(меньше файл), тайминг-шит — 30 fps, как в композиции AE.

Посмотреть превью без AE:

```bash
python -m http.server 8000 --directory docs/ae
# открыть http://localhost:8000
```

Пересобрать всё после правки текстов бота:

```bash
make ae-assets            # или: python scripts/generate_ae_assets.py
python scripts/generate_ae_assets.py --only 03_picking_genres --fps 20
python scripts/generate_ae_assets.py --backdrop dark      # тёмная подложка канвы
python scripts/generate_ae_assets.py --frames             # + PNG-последовательность кадров
```

Pillow нужен только для генерации (уже в `requirements-dev.txt`), самому боту
он не требуется.

## 1. Как устроена анимация

Общая идея повторяет настоящий Telegram: сначала карточка «проявляется», затем
бот «печатает…», потом пузырём приходит сообщение, следом появляются кнопки, и
в конце одна из кнопок «нажимается». В карточке «Выбор жанра» показано главное
действие экрана: нажатие на жанр ставит ✔, сообщение и клавиатура обновляются,
а кнопки плавно съезжают вниз, потому что сообщение стало выше.

Соответствие эффектов генератора и свойств After Effects:

| Эффект в `timeline.json` | Что делать в AE | Ключевые кадры |
|--------------------------|-----------------|----------------|
| `fade` | `Opacity` | 0 → 100 за `duration_s` |
| `slide_up` | `Opacity` + `Position` (Y) | Opacity 0 → 100; Y = `Y₀ + offset_px × scale` → `Y₀` |
| `pop` | `Scale` + `Opacity` | Scale 86 → 100 с перелётом, Opacity 0 → 100 |
| `keyboard_up` | `Position` (Y) | Y = `Y₀ + offset_px × scale` → `Y₀` |
| `shift_down` | `Position` (Y) | Y = `Y₀` → `Y₀ + offset_px × scale` (сообщение выросло) |
| `tap` | `Scale` | 100 → 94 → 100 (имитация нажатия) |
| `hide` | `Opacity` | 100 → 0 (мгновенная смена варианта сообщения) |

`scale` — коэффициент карточки из `timeline.json` (поле `scale`, ≈ 1.6–2.6):
смещения в JSON указаны в «экранных» пикселях макета, в AE их нужно умножить.

Время в кадрах AE уже посчитано: у каждого шага есть `ae.in_frame`,
`ae.duration_frames`, `ae.out_frame` (30 fps).

## 2. Сборка композиции в After Effects

1. **Композиция.** `Composition → New Composition`: 1080×1350, 30 fps,
   длительность 6.0 с (карточка 1) или 7.5 с (карточки 2 и 3).
2. **Слои.** `File → Import → Multiple Files…` → папка
   `docs/ae/layers/<экран>` (все PNG сразу). Или `File → Scripts → Run Script
   File…` → `docs/ae/import_layers.jsx`: скрипт сам создаст композицию,
   разложит слои по позициям из `timeline.json` и проставит ключевые кадры
   `fade` / `slide_up` / `hide`.
3. **Порядок и позиции.** Слои кладите сверху вниз в порядке поля `z` из
   `timeline.json` (`caption` поверх `bubble`, `bubble` поверх `backdrop`).
   Позиция каждого слоя — `x + width/2`, `y + height/2` из того же JSON.
4. **Ключевые кадры.** Для каждого шага из раскадровки поставьте ключи по
   таблице соответствия выше. На всех ключах — `F9` (Easy Ease), у движения
   включите Motion Blur (`переключатель на слое`).
5. **«Перелёт» и упругость.** Вместо ручного третьего ключа на `pop` можно
   повесить expression на Scale:

   ```javascript
   amp = 8; freq = 2.4; decay = 7;
   t = time - inPoint;
   s = 86 + 14 * (1 - Math.exp(-decay * t) * Math.cos(freq * t * 2 * Math.PI))
       + amp * Math.exp(-decay * t) * Math.sin(freq * t * 2 * Math.PI);
   [s, s]
   ```

   Для «нажатия» (`tap`) достаточно трёх ключей Scale: 100 → 94 → 100 за 0.3 с.
6. **Текст.** Заголовок и описание каждой карточки лежат в `timeline.json`
   (`ae_text_layers`) — это готовые строки для текстовых слоёв: заголовок 64 px
   `#16202E`, описание 34 px `#4A5568`. Шрифт — Segoe UI / Inter / Manrope.
   Схема «карточка сверху, текст снизу» собрана в `preview.html`; для неё
   удобно сделать композицию повыше (например 1080×1920) и опустить карточку
   в верхнюю половину.
7. **Наложение на свой фон/текст.** GIF не умеет полупрозрачность, поэтому для
   варианта «карточка плавает над моим текстом» используйте прозрачность:
   `generate_ae_assets.py --backdrop none --frames` даёт PNG-последовательность
   с альфой (`docs/ae/frames/<экран>`), из неё в AE или ffmpeg собирается
   WebM (VP9 + alpha) / ProRes 4444 — их можно класть поверх чего угодно.

## 3. Экспорт GIF

**Через Adobe Media Encoder:** `Composition → Add to Media Encoder Queue`,
формат **GIF**, пресет поправить так: ширина **720 px** (высота сама, ≈900),
кадры **15**, палитра **Adaptive, 128–256 цветов**, Dithering **Diffusion**.
Такие настройки дают ≈0.7–1.0 МБ — как черновые GIF в `docs/ae/cards`.

**Через PNG-последовательность и ffmpeg** (если Media Encoder недоступен):

```bash
python scripts/generate_ae_assets.py --frames
ffmpeg -framerate 15 -i docs/ae/frames/01_start/frame_%04d.png \
       -vf "scale=720:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=128[p];[s1][p]paletteuse=dither=bayer" \
       -loop 0 docs/ae/cards/01_start_ffmpeg.gif
```

**Куда подойдут GIF:**

| Куда | Ограничение | Наши карточки |
|------|-------------|---------------|
| Telegram (`send_animation`) | до 5 МБ, GIF конвертируется в mp4 | 0.7–0.9 МБ ✔ |
| README / документация GitHub | формально до 10 МБ, комфортно до 3 МБ | ✔ |
| Презентация, защита проекта | без ограничений | ✔ |
| Соцсети | обычно до 8–15 МБ | ✔ |

Если файл получился тяжелее нужного: уменьшите ширину (640 px), кадры (12 fps)
или палитру (64 цвета) — либо отрежьте паузу для чтения в конце.

## 4. Что можно улучшить в AE сверх черновика

Черновые GIF показывают тайминги и порядок; «вкус» добавляется в AE вручную:

* лёгкое размытие в движении (Motion Blur / Pixel Motion Blur) на въездах;
* блик-«проблеск» по карточке в конце (слой с градиентом + Blend Mode Screen);
* реальные обложки игр вместо текстовых строк: ссылки `background_image` есть в
  `docs/06_vneshnie_api.md` и в демо-данных (`media.rawg.io/media/games/…jpg`) —
  положите их отдельным слоем под текст строки;
* звук «клика» на шагах `tap` (для видеоверсии);
* свой фон канвы: `--backdrop dark` или прозрачная канва + ваш градиент.

Все числа для этих доработок уже лежат в `timeline.json` — правьте движение там
и пересобирайте черновики командой `make ae-assets`, чтобы сравнить версии.
