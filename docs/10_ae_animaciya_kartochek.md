# 10. Обучающие видеокарточки (Adobe After Effects)

Три обучающие карточки — **приветствие**, **выбор жанра**, **выбор игры** —
это не просто запись интерфейса, а инструкции: в кадре 16:9 слева работает
«телефон» с настоящим интерфейсом бота, справа — панель шагов обучения, а в
моменты нажатий появляется кольцо подсветки. Тексты и кнопки берутся из
`gamehunter.presentation.texts` / `keyboards` (как и SVG-мокапы), подписи
шагов — из `texts.TUTORIAL_STEPS`: бот отправляет эти же строки под GIF.

Готовые GIF использует **Экран 13 «Обучение»** (кнопка главного меню
«🎬 Как пользоваться», `gateway.send_animation`).

| Файл | Что это |
|------|---------|
| `gamehunter/assets/tutorial/01_start.gif` | карточка 1 «Приветствие» — 6.0 с, ≈3.2 МБ |
| `gamehunter/assets/tutorial/03_picking_genres.gif` | карточка 2 «Выбор жанра» с отметками ✔ — 7.5 с, ≈3.5 МБ |
| `gamehunter/assets/tutorial/04_game_list.gif` | карточка 3 «Выбор игры» — 7.5 с, ≈3.0 МБ |
| `docs/ae/layers/<экран>/*.png` | слои с прозрачностью: подложка, шапка, «печатает…», пузырь, ряды кнопок, клавиатура, подпись, панель шагов, кольца подсветки |
| `docs/ae/timeline.json` | тайминг-шит: канва 1920×1080, позиции «телефона», шаги анимации в секундах и кадрах AE (**60 fps**), easing |
| `docs/ae/preview.html` | живое превью всех карточек |
| `docs/ae/import_layers.jsx` | скрипт AE: импорт слоёв, сборка композиции, ключевые кадры Opacity/Position/Scale |

Канва — **1920×1080 (16:9)**, частота раскадровки и композиции AE — **60 fps**.
GIF сохраняются шириной **960 px** (960×540) — так они весят 3.0–3.5 МБ и
проходят в лимит Telegram с запасом.

Посмотреть превью без AE (сервер запускается **из корня репозитория**, чтобы
GIF из `gamehunter/assets/tutorial` были доступны по относительным путям):

```bash
python -m http.server 8000
# открыть http://localhost:8000/docs/ae/preview.html
```

Пересобрать всё после правки текстов бота (полный прогон ≈ 70 с):

```bash
make ae-assets            # или: python scripts/generate_ae_assets.py
python scripts/generate_ae_assets.py --only 03_picking_genres
python scripts/generate_ae_assets.py --backdrop dark      # тёмная подложка канвы
python scripts/generate_ae_assets.py --frames             # + PNG-последовательность кадров
python scripts/generate_ae_assets.py --gif-width 1280 --fps 30
python scripts/generate_ae_assets.py --no-gif             # только слои и timeline.json
```

⚠️ `--only <карточка>` перезаписывает `timeline.json` и `preview.html`
содержимым одной карточки — перед коммитом сделайте полный прогон.

Pillow нужен только для генерации (уже в `requirements-dev.txt`), самому боту
он не требуется. Кадры собираются потоково (`iter_card_frames` →
`export_card_frames`): в памяти держится один кадр, иначе ~450 кадров
1920×1080 съедают несколько гигабайт.

## 1. Как устроена анимация

Карточка повторяет настоящий Telegram: «телефон» проявляется, бот «печатает…»,
пузырём приходит сообщение, появляются кнопки, одна из кнопок «нажимается»
(кольцо подсветки `pointer_N`). Одновременно справа на панели шагов зажигаются
пункты инструкции (`step_N_on/off`, `progress`) — в те же моменты, что и
действия в телефоне (`step_times` карточки).

Соответствие эффектов генератора и свойств After Effects:

| Эффект в `timeline.json` | Что делать в AE | Ключевые кадры |
|--------------------------|-----------------|----------------|
| `fade` | `Opacity` | 0 → 100 за `duration_s` |
| `slide_up` | `Opacity` + `Position` (Y) | Opacity 0 → 100; Y = `Y₀ + offset_px × scale` → `Y₀` |
| `pop` | `Scale` + `Opacity` | Scale 86 → 100 с перелётом, Opacity 0 → 100 |
| `keyboard_up` | `Position` (Y) | Y = `Y₀ + offset_px × scale` → `Y₀` |
| `shift_down` | `Position` (Y) | Y = `Y₀` → `Y₀ + offset_px × scale` (сообщение выросло) |
| `tap` | `Scale` | 100 → 94 → 100 (имитация нажатия) |
| `hide` | `Opacity` | 100 → 0 (мгновенная смена варианта сообщения) |

`scale` — коэффициент «телефона» из `timeline.json` (поле `scale`, ≈ 1.2–2.2):
смещения указаны в «экранных» пикселях макета, в AE их нужно умножить.

Время в кадрах AE уже посчитано: у каждого шага есть `ae.in_frame`,
`ae.duration_frames`, `ae.out_frame` (**60 fps**).

### Ключевые моменты карточек (кадры при 60 fps)

**Карточка 1 «Приветствие» (6.0 с = 360 кадров):**

| 1.75–2.20 | 105–132 | клавиатура выезжает снизу |
| 2.55 | 153 | шаг 3 + кольцо подсветки: нажатие кнопки «Старт» |
| 2.90–6.00 | 174–360 | пауза для чтения текста |

**Карточка 2 «Выбор жанра» (7.5 с = 450 кадров):**

| Секунды | Кадры AE | Что происходит |
|---------|----------|----------------|
| 0.20 | 12 | шаг 1: «В главном меню нажмите „Подобрать игру“…» |
| 1.65 | 99 | шаги жанров появляются по одному; шаг 2 панели |
| 3.30 | 198 | нажатие на жанр Action → ✔, сообщение обновляется, кнопки съезжают |
| 4.30 | 258 | нажатие на жанр RPG; шаг 3: «…нажмите „Показать подборку“» |

Полная раскадровка (все шаги, easing, смещения, позиции слоёв) — в
`docs/ae/timeline.json`, поля `steps` и `layers` каждой карточки.

### Тайминг кадров GIF

60 fps невозможно точно выразить в сотых долях секунды (единица хранения GIF),
поэтому длительности кадров чередуются **2, 2, 1 сантисекунды** (`frame_cs`) —
в среднем ровно 1/60 с, и суммарная длительность совпадает с раскадровкой
(6000 / 7500 / 7500 мс). Одинаковые кадры подряд сливаются с суммированием
длительности: Pillow иначе молча выбрасывает дубликаты. Статический хвост не
перерисовывается — генератор останавливается после последнего шага анимации.

## 2. Сборка композиции в After Effects

1. **Композиция.** `Composition → New Composition`: **1920×1080, 60 fps**,
   длительность 6.0 с (карточка 1) или 7.5 с (карточки 2 и 3).
2. **Слои.** `File → Import → Multiple Files…` → папка
   `docs/ae/layers/<экран>` (все PNG сразу). Или `File → Scripts → Run Script
   File…` → `docs/ae/import_layers.jsx`: скрипт сам создаст композицию,
   разложит слои по позициям из `timeline.json` и проставит ключевые кадры
   `fade` / `slide_up` / `hide`.
3. **Порядок и позиции.** Слои кладите сверху вниз в порядке поля `z` из
   `timeline.json` (`caption` поверх `bubble`, `bubble` поверх `backdrop`,
   `pointer_N` поверх кнопок). Позиция каждого слоя — `x + width/2`,
   `y + height/2` из того же JSON.
4. **Ключевые кадры.** Для каждого шага из раскадровки поставьте ключи по
   таблице соответствия выше. На всех ключах — `F9` (Easy Ease), у движения
   включите Motion Blur (`переключатель на слое`).
5. **«Перелёт» и упругость.** Вместо ручного третьего ключа на `pop` можно
   повесить expression на Scale:

   ```javascript
   amp = 8; freq = 2.4; decay = 7;
   t = time - inPoint;
   s = 86 + 14 * (1 - Math.exp(-decay * t) * Math.cos(freq * t * 2 * Math.PI))
       + amp * Math.exp(-decay * t) * Math.sin(freq * t * 2 * Math.PI);
   [s, s]
   ```

   Для «нажатия» (`tap`) достаточно трёх ключей Scale: 100 → 94 → 100 за 0.3 с.
   Кольца подсветки (`pointer_N`) появляются шагом `pop` и гаснут шагом `hide`
   через секунду после нажатия.
6. **Текст.** Заголовок и описание каждой карточки лежат в `timeline.json`
   (`ae_text_layers`) — готовые строки для текстовых слоёв. Тексты шагов
   обучения уже нарисованы на панели (`panel_heading`, `step_N_*`), в AE их
   можно заменить живыми текстовыми слоями из поля `tutorial_steps`.
7. **Наложение на свой фон/текст.** GIF не умеет полупрозрачность, поэтому для
   варианта «карточка плавает над моим фоном» используйте прозрачность:
   `generate_ae_assets.py --backdrop none --frames` даёт PNG-последовательность
   с альфой (`docs/ae/frames/<экран>`), из неё в AE или ffmpeg собирается
   WebM (VP9 + alpha) / ProRes 4444 — их можно класть поверх чего угодно.

## 3. Экспорт GIF

Генератор уже собирает финальные GIF (покадровая адаптивная палитра, 128
цветов — она сохраняет тонкое кольцо подсветки; общая палитра в Pillow 12 его
теряет). Если собираете версию в AE:

**Через Adobe Media Encoder:** `Composition → Add to Media Encoder Queue`,
формат **GIF**, пресет: ширина **960 px** (высота сама, 540), кадры **60**
(или 30 для меньшего файла), палитра **Adaptive, 128 цветов**, Dithering
**Diffusion**.

**Через PNG-последовательность и ffmpeg** (если Media Encoder недоступен):

```bash
python scripts/generate_ae_assets.py --frames
ffmpeg -framerate 60 -i docs/ae/frames/01_start/frame_%04d.png \
       -vf "scale=960:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=128[p];[s1][p]paletteuse=dither=bayer" \
       -loop 0 gamehunter/assets/tutorial/01_start_ffmpeg.gif
```

**Куда подойдут GIF:**

| Куда | Ограничение | Наши карточки |
|------|-------------|---------------|
| Telegram (`send_animation`, Экран 13) | до 50 МБ, но комфортно до 5 МБ | 3.0–3.5 МБ ✔ |
| README / документация GitHub | формально до 10 МБ, комфортно до 3 МБ | на границе ✔ |
| Презентация, защита проекта | без ограничений | ✔ |

Если файл получился тяжелее нужного: уменьшите ширину (`--gif-width 720`),
кадры (`--fps 30`) или палитру (`colors=64` в `export_card_frames`) — либо
отрежьте паузу для чтения в конце (поле `duration` карточки).

## 4. Что можно улучшить в AE сверх черновика

GIF из репозитория — финальные обучающие ролики, которые шлёт бот; «вкус»
добавляется в AE вручную:

* лёгкое размытие в движении (Motion Blur / Pixel Motion Blur) на въездах;
* блик-«проблеск» по карточке в конце (слой с градиентом + Blend Mode Screen);
* реальные обложки игр вместо текстовых строк: ссылки `background_image` есть в
  `docs/06_vneshnie_api.md` и в демо-данных (`media.rawg.io/media/games/…jpg`) —
  положите их отдельным слоем под текст строки;
* звук «клика» на шагах `tap` (для видеоверсии);
* свой фон канвы: `--backdrop dark` или прозрачная канва + ваш градиент.

Все числа для этих доработок уже лежат в `timeline.json` — правьте движение там
и пересобирайте карточки командой `make ae-assets`, чтобы сравнить версии.
